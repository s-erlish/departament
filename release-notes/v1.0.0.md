Первый выпуск departament для ПК на GitHub. Дальше программа обновляется сама из этих релизов.

## Установка

1. Скачайте `departament-setup.exe` из списка файлов ниже и запустите его.
2. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае». Программа пока не подписана сертификатом разработчика.
3. Установщик попросит права администратора и поставит программу в `C:\Program Files\departament`. В конце галочка «Запустить departament от имени администратора» уже стоит.

Удаляется программа через «Параметры», раздел «Приложения». Настройки и серверы при удалении стираются, только если вы согласитесь.

## Обновления

Программа сама проверяет новые выпуски на этой странице: через полминуты после запуска и потом раз в несколько часов. Когда выходит новая версия, в строке окна появляется «Обновить». Программа скачивает обновление, сверяет контрольную сумму и после вашего подтверждения перезапускается в новую версию. Если VPN был подключён, он подключится снова сам через несколько секунд.

## Что в этом выпуске

- Ядра Xray 26.3.27 и sing-box 1.14.1 закреплены и приходят вместе с программой. Выход новой версии ядра больше не ломает подключение.
- Режим «весь трафик» (TUN) и серверы Remnawave: адрес сервера определяется в обход туннеля, наборы правил лежат в комплекте.
- Запуск сразу на экране серверов, без мелькания экрана входа. Окно открывается сразу в своём размере, значок в трее появляется вместе с окном.
- Обновление подписки не пересобирает список и не рвёт соединение, если ваш сервер не изменился.
- Прямой DNS на Яндексе.
- Выход из «Прокси по приложениям» перезапускает VPN, только если правила действительно изменились.
- Двойной щелчок по верхней полосе окна разворачивает его на весь экран.

## Контрольная сумма

SHA-256 архива обновления лежит в файле `departament-windows-x64.zip.sha256`.
