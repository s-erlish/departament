## Что в этом выпуске

- Плашка «Вышла версия …» теперь появляется при каждом запуске приложения, если новая версия уже вышла. Раньше приложение после проверки час не спрашивало снова, и плашку можно было увидеть только через «Проверить обновления».
- При возвращении в уже открытое приложение оно тоже проверяет обновления, если с прошлой проверки прошло больше пяти минут.

## Обновления

Откройте «Настройки» → «Проверить обновления» или нажмите на плашку на главной: приложение скачает APK и откроет установку. Серверы, подписка и вход при обновлении сохраняются.
