## Что в этом выпуске

- Уведомление о подключении стоит в шторке наверху, над остальными уведомлениями, а не в разделе «Без звука». Оно по-прежнему без звука.
- Ссылка с сайта больше не может сама поменять правила маршрутизации: приложение сначала спрашивает, заменять ли их. Раньше такая ссылка могла пустить весь трафик мимо VPN, пока на экране было «Подключено».
- Подписку по ссылке можно добавить только с сайта departament.
- «Российские приложения» в режиме «Только выбранные» больше не пускают банки и Госуслуги через VPN. Импорт списка приложений из буфера больше не переворачивает выбор.
- После смены настроек подключение больше не может показывать «Подключено» без работающего VPN. Если для нового режима нужно разрешение на VPN, приложение его спросит.
- После восстановления из резервной копии или переноса на новый телефон вход больше не ломается: приложение просит войти заново. Вход в резервные копии больше не попадает.
- Оплата с баланса при нехватке денег больше не выглядит успешной.
- Приложение больше не закрывается, если повернуть экран во время пополнения.
- Вручную добавленные серверы видны и тогда, когда есть подписка.
- Передача подписки на телевизор работает только в домашней сети.
- Прочие исправления: запуск в режиме «Только прокси», подписка, возвращавшаяся после удаления.

## Обновления

Нажмите «Обновить» в окне о новой версии или откройте «Настройки» → «Проверить обновления»: приложение скачает APK и откроет установку. Серверы, подписка и вход при обновлении сохраняются.
