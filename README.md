# departament

VPN для Windows: подключение к серверам вашей подписки одним нажатием.

**[Скачать для Windows](https://github.com/s-erlish/departament/releases/latest/download/departament-setup.exe)** · [Все выпуски](https://github.com/s-erlish/departament/releases)

## Возможности

- Подключение одним нажатием к серверам подписки.
- Режим «TUN» для всех программ компьютера или системный прокси.
- Прокси по приложениям: через VPN идут только выбранные программы или все, кроме них.
- Вход в аккаунт departament: подписка и серверы подключаются сами.
- Обновления приходят внутри программы.

## Установка

1. Скачайте `departament-setup.exe` со страницы [последнего выпуска](https://github.com/s-erlish/departament/releases/latest) и запустите его.
2. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае». Программа пока не подписана сертификатом разработчика.
3. Установщик попросит права администратора и поставит программу в `C:\Program Files\departament`. В конце программа запустится сама.

Удаляется программа через «Параметры», раздел «Приложения». Настройки и серверы при удалении стираются, только если вы согласитесь.

## Обновления

Программа сама проверяет выпуски на этой странице: через полминуты после запуска и потом раз в несколько часов. Когда выходит новая версия, в строке окна появляется «Обновить». Программа скачивает обновление, сверяет его контрольную сумму и после вашего подтверждения перезапускается в новую версию. Если VPN был подключён, он подключится снова сам.

## Системные требования

- Windows 10 или 11, 64 бита.
- Права администратора: без них не работает режим «весь трафик».

## Исходный код

Весь код программы лежит здесь. Сама программа находится в папке `departament/departament.Desktop`, помощник обновления в `departament/AmazTool`, установщик в `installer`. Каждый выпуск собирается из этого репозитория в GitHub Actions. Как выпустить новую версию, написано в [RELEASING.md](RELEASING.md).
